# QA 작업 기준

이 폴더는 현재 QA 작업의 기준 폴더이다.

## 현재 작업 원칙
- 배포 환경과 로컬 환경 결과를 섞지 않는다.
- 정상 입력 대표 케이스와 유해/비정상 입력 케이스를 분리한다.
- 분석 문서와 원본 증빙을 분리한다.
- TC 작성은 마지막 단계에서 진행한다.

## 현재 폴더 구조

### 01_배포환경
- 실제 서비스 기준 증빙

#### 정상입력_대표케이스/헬스장
- 정상 입력 대표 케이스
- 화면캡처: 브라우저 화면 증빙
- 네트워크: 요청/응답 증빙
- 메모: 케이스별 텍스트 메모

#### 유해입력
- 실제 표현 기반 유해 입력 배포 결과
- 현재는 배포 공통 500 장애 때문에 정책 판정보다는 장애 증빙 성격이 강함

### 02_로컬환경
- localhost 기준 재테스트와 DB 확인 자료

#### 정상입력_대표케이스/헬스장
- 로컬 생성 성공 및 DB 저장 확인 자료

#### 유해입력
- 실제표현
  - 성적
  - 차별혐오
  - 정치선동
  - 위험폭력
- 구조오류
- 긴문자열_형식오류

### 03_분석정리
- 요약문서
- 증빙인덱스
- 역QA정리
- 중간결론

### 04_TC
- 엑셀원본
- 작성중메모

### 99_보류
- 옛자료
- 중복파일
- 정리전파일

## 주의 사항
- `qa/testcase` 폴더는 원본 엑셀 파일이 열려 있어 잠긴 상태일 수 있다.
- 실제 작업 기준 TC 파일은 `04_TC/엑셀원본/TC_260430.xlsx` 복사본을 우선 사용한다.
- 예전 구조에서 옮긴 폴더와 파일은 `99_보류` 아래에 남겨 두었다.

## 현재 우선순위
1. 로컬 재테스트 결과를 문서에 반영
2. 유해 입력과 비정상 입력 분류 기준 정리
3. TC 초안 작성
