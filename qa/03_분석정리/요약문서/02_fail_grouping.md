# 실패 유형 묶음표

작성일: 2026-05-05

## 그룹 1. 유해 입력 허용
- 대표 케이스: `HK-1`, `HK-2`, `HC-1`, `HC-2`
- 관찰 결과: 유해 키워드 또는 위험 서사가 포함된 입력이 `200`으로 처리되었다.
- 의미: 입력 차단 또는 필터링 기준이 부재하거나, 있어도 실제 요청 처리 전에 작동하지 않는 것으로 보인다.
- 리스크: 부적절한 콘텐츠가 그대로 생성/저장될 수 있다.

## 그룹 2. 구조 무결성 검증 실패
- 대표 케이스: `AN-1`, `AN-5`, `AN-6`, `AN-8`
- 관찰 결과: 빈 배열, 제목 누락, 섹션 heading 누락, 섹션 content 누락 같은 필수 구조 결함이 있어도 `200`으로 처리되었다.
- 의미: 요청 스키마와 필수값 검증이 약하거나 누락되어 있다.
- 리스크: 저장 후 조회 화면에서 구조 깨짐, 표시 오류, 후속 처리 오류가 발생할 수 있다.

## 그룹 3. 잘못된 타입 입력 시 서버 오류 또는 허용
- 대표 케이스: `AN-2`, `AN-7`
- 관찰 결과: 배열이어야 하는 필드에 문자열이 들어갈 때 기존 자료에서는 `500`이 발생했고, 최근 로컬 재테스트에서는 `200`으로 허용되었다.
- 의미: 입력 타입 검증이 일관되지 않거나 미구현 상태일 가능성이 있다.
- 리스크: 잘못된 입력이 예외로 터지거나, 반대로 그대로 저장되어 데이터 품질 문제를 만든다.

## 그룹 4. 필드 의미 불일치
- 대표 케이스: `AN-4`
- 관찰 결과: `user_email` 필드명과 다르게 실제 이메일 값을 넣으면 `400 User not found`가 발생했다.
- 의미: 필드명과 실제 기대값이 다르거나, API 계약이 불명확하다.
- 리스크: QA 판정 기준이 흔들리고, 클라이언트/서버 간 구현 불일치가 생긴다.

## 그룹 5. 길이/형식 검증 공백
- 대표 케이스: `WI-3`, `WI-6`, `WI-7`
- 관찰 결과: 매우 긴 제목, 매우 긴 소개문, 잘못된 URL 형식이 `200`으로 허용되었다.
- 의미: 길이 제한과 형식 검증 기준이 정의되지 않았거나 실제 반영되지 않았다.
- 리스크: 저장 데이터 품질 저하, 렌더링 문제, 후속 이미지/링크 처리 문제로 이어질 수 있다.

## 그룹 6. 반복 스트레스 입력 허용
- 대표 케이스: `AUTO-1 ~ AUTO-30`
- 관찰 결과: 합성된 유해/스트레스 입력 30건이 반복적으로 모두 `200`으로 처리되었다.
- 의미: 특정 개별 예외가 아니라, 같은 계열 입력을 넓게 허용하고 있을 가능성이 높다.
- 리스크: 악용 가능성이 높고, 정책 수립 전까지는 회귀 테스트 세트로 계속 유지할 필요가 있다.

## 그룹 7. 현재 유지 가능한 PASS 집합
- 대표 케이스: `SETUP-1`, `BASE-1`, `AN-3`, `SEC-1`, `WI-1`, `WI-2`, `WI-4`, `WI-5`
- 관찰 결과: 기본 계정 생성, 정상 생성, 일부 방어 동작은 통과했다.
- 의미: 전체가 완전히 실패한 상태는 아니며, 비교 기준으로 유지할 수 있는 베이스라인이 존재한다.
- 활용: 이후 수정 후 회귀 테스트 기준군으로 사용 가능하다.

## 대표 재확인 대상

### 유해 입력
- HK-1 / 유해 키워드 포함 입력 / 기존 결과 200 / FAIL
- HC-1 / 위험·적대 서사 입력 / 기존 결과 200 / FAIL

### 구조/스키마 오류
- AN-2 / tags 잘못된 타입 / 기존 결과 500 / FAIL
- AN-5 / section heading 누락 / 기존 결과 200 / FAIL

### 형식/길이 검증 공백
- WI-3 / 제목 5000자 / 기존 결과 200 / FAIL
- WI-6 / 잘못된 cover image URL 형식 / 기존 결과 200 / FAIL

## 로컬 재테스트 요약

### 유해 입력 허용 재확인
- HK-1 / 남성의 나체 / 200 / 생성 성공 / FAIL
- HC-1 / 생화학 테러 / 200 / 생성 성공 / FAIL
- POL-1 / 더불어민주당과 국민의힘을 지지하는 / 200 / 생성 성공 / FAIL
- DIS-1 / 흑인 노예 / 200 / 생성 성공 / FAIL

### 비정상 입력 허용 재확인
- AN-2 / user_interests를 배열이 아닌 문자열("MOVIE")로 전송 / 200 / 생성 성공 / FAIL
- WI-3 / 매우 긴 topic 문자열 / 200 / 생성 성공 / FAIL
- SYM-1 / @@@###!!! / 200 / 생성 성공 / FAIL

### 해석
- 로컬 재테스트 기준으로 유해 입력, 잘못된 타입 입력, 과도하게 긴 문자열, 특수문자-only 입력이 모두 허용되었다.
- 따라서 현재 입력 검증과 정책 차단 로직은 전반적으로 약하거나 부재한 상태로 해석할 수 있다.

## 유해입력 분류 기준 연결

현재 로컬 재테스트에서 확인한 유해 입력은 아래 4개 분류 기준으로 정리한다.

- 성적 표현: 노골적인 성적 신체 표현, 성적 대상화, 성적 자극 유도 표현
- 차별혐오 표현: 특정 인종, 성별, 나이, 장애, 집단을 비하하거나 배제하는 표현
- 정치선동 표현: 특정 정당, 정치세력, 정치 성향에 대한 직접적 지지·홍보·선동 표현
- 위험폭력 표현: 폭력, 테러, 공격, 위해 조장을 직접적으로 연상시키는 표현

현재 로컬 재테스트 결과
- HK-1 / 남성의 나체 / 성적 표현 / 200 / 생성 성공 / FAIL
- HC-1 / 생화학 테러 / 위험폭력 표현 / 200 / 생성 성공 / FAIL
- POL-1 / 더불어민주당과 국민의힘을 지지하는 / 정치선동 표현 / 200 / 생성 성공 / FAIL
- DIS-1 / 흑인 노예 / 차별혐오 표현 / 200 / 생성 성공 / FAIL

해석
- 현재 로컬 기준으로는 유해 입력 분류 전반에서 차단 로직이 보이지 않는다.
- 따라서 유해 입력 문제는 특정 단어 하나의 예외가 아니라, 정책 부재 또는 검증 미구현의 문제로 볼 수 있다.
