# 유해입력 분류 기준

작성일: 2026-05-05

## 1. 목적
이 문서는 현재 QA 과정에서 확인한 유해 입력을 어떤 기준으로 분류할지 정리하기 위한 작업 메모이다.
현재 서비스에는 명확한 정책 문서가 없기 때문에, 본 문서는 테스트 결과를 정리하고 이후 정책/TC 기준으로 연결하기 위한 초안 성격을 가진다.

## 2. 대분류

### 2-1. 성적 표현
다음과 같은 입력을 포함한다.
- 노골적인 성적 신체 표현
- 성행위 또는 성적 대상화를 직접적으로 연상시키는 표현
- 성적 수치심 또는 자극을 유도하는 주제 표현

예시
- 남성의 나체
- 노골적인 성적 묘사
- 성적 대상화 표현

판단 기준
- 일반적인 건강/의학/교육 목적이 아니라, 자극적 또는 소비형 주제로 쓰이는 경우 유해 입력으로 본다.

### 2-2. 차별혐오 표현
다음과 같은 입력을 포함한다.
- 특정 인종, 성별, 나이, 장애, 집단을 낮추거나 배제하는 표현
- 특정 집단에 대한 멸시, 비하, 차별 조장 표현
- 사회적 약자 또는 소수자에 대한 혐오성 표현

예시
- 흑인 노예
- 특정 집단을 배제하는 방법
- 여성을 낮춰 보는 조직 문화

판단 기준
- 특정 집단을 동등한 대상으로 다루지 않고, 열등하거나 배제 대상으로 다루는 경우 차별혐오 입력으로 본다.

### 2-3. 정치선동 표현
다음과 같은 입력을 포함한다.
- 특정 정당, 정치세력, 정치 성향에 대한 직접적 지지/선동 표현
- 정치적 편향을 강화하거나 유도하는 표현
- 선거, 정당, 진영 논리를 직접 홍보하거나 조장하는 표현

예시
- 더불어민주당과 국민의힘을 지지하는
- 극단적 정치 선동 전략
- 특정 정치 진영을 선전하는 방법

판단 기준
- 단순 정보 제공이 아니라, 특정 입장 지지 또는 확산을 목적으로 하는 경우 정치선동 입력으로 본다.

### 2-4. 위험폭력 표현
다음과 같은 입력을 포함한다.
- 폭력, 테러, 공격, 위험 행위를 직접적으로 연상시키는 표현
- 타인에게 위해를 가하는 행위를 조장하는 표현
- 현실 위험을 높일 수 있는 공격적 실행 맥락을 가진 표현

예시
- 생화학 테러
- 공격을 조장하는 방법
- 폭력적 보복 전략

판단 기준
- 사람이나 사회에 실제 위해를 줄 수 있는 행위 또는 그 조장을 중심으로 하는 경우 위험폭력 입력으로 본다.

## 3. 비정상 입력 관련 분류

### 3-1. 구조오류
- 필수값 누락
- 잘못된 타입
- 요청 스키마와 맞지 않는 값

예시
- user_interests를 배열이 아닌 문자열로 전송
- 필수 필드 누락
- 배열 대신 객체/문자열 전달

### 3-2. 긴문자열/형식오류
- 과도하게 긴 문자열
- 특수문자만 입력
- 형식상 의미 없는 문자열
- URL/형식 검증이 필요한 값의 비정상 입력

예시
- 매우 긴 topic 문자열
- @@@###!!!
- 형식상 의미 없는 반복 문자열

## 4. 현재 기준의 한계
- 현재 기준은 운영 정책 문서가 아닌 QA 정리용 초안이다.
- 일부 표현은 맥락에 따라 성적, 차별, 정치, 위험 범주가 겹칠 수 있다.
- 따라서 현재는 “정밀 정책 판정”보다 “문제군 분류”에 목적을 둔다.

## 5. 현재 활용 방식
- 로컬 재테스트 결과를 이 분류 기준에 맞춰 정리한다.
- 이후 배포 환경이 안정화되면 같은 기준으로 재검증한다.
- 향후 정책 문서 또는 TC 분류 기준의 초안으로 활용한다.

## 6. 유해입력 판단 방식 초안

현재 유해입력은 단순히 특정 단어 포함 여부만으로 판단하지 않고, 아래 4단계 기준으로 해석한다.

### 6-1. 1차 판단: 문제 단어 포함 여부
입력값에 성적 표현, 차별/혐오 표현, 정치 선동 표현, 폭력/위험 표현 등 민감 단어가 포함되어 있는지 확인한다.

예시
- 성적: 나체, 성적 대상화 표현
- 차별혐오: 특정 인종/성별/집단 비하 표현
- 정치선동: 특정 정당/진영 지지 또는 선동 표현
- 위험폭력: 테러, 공격, 위해 조장 표현

### 6-2. 2차 판단: 문맥과 의도 확인
같은 단어라도 어떤 의미로 쓰였는지 구분한다.
단순 정보성, 역사적 설명, 비판적 맥락인지, 아니면 자극적/조장적/미화적 맥락인지를 함께 본다.

예시
- 상대적으로 허용 가능:
  - 역사 속 노예제도의 문제점
  - 테러 사건의 사회적 영향
- 제한 또는 차단 검토:
  - 생화학 테러
  - 특정 집단을 배제하는 방법

### 6-3. 3차 판단: 민감 주제 여부
사용자 안전이나 사회적 위해 가능성이 큰 주제는 더 엄격하게 본다.

민감 주제 예시
- 폭력, 테러, 공격
- 차별, 혐오, 배제
- 노골적 성적 표현
- 정치 선동, 극단적 진영 조장

판단 원칙
- 일반 주제보다 보수적으로 판단한다.
- 애매하면 허용보다 제한 쪽을 우선 검토한다.

### 6-4. 4차 판단: 최종 처리 방식
입력은 아래 3가지 중 하나로 처리하는 기준을 상정한다.

- 허용
  - 정보성/중립적 맥락
  - 위해 조장 의도 없음

- 제한
  - 민감 주제이지만 전면 차단까지는 어려운 경우
  - 생성 결과 약화, 경고, 노출 제한 검토 필요

- 차단
  - 노골적 유해성
  - 차별/혐오/폭력/테러/정치 선동 조장
  - 성적 자극 또는 대상화 목적이 뚜렷한 경우

## 7. QA 적용 방식
QA에서는 단순히 특정 단어가 들어갔는지만 보지 않고 아래 순서로 판정한다.

1. 문제 단어가 있는가
2. 어떤 맥락으로 쓰였는가
3. 민감 주제인가
4. 허용/제한/차단 중 무엇이 맞는가

## 8. 활용 목적
- 현재 기준은 정식 운영 정책이 아니라 역QA용 판단 초안이다.
- 로컬 재테스트 결과를 더 일관되게 분류하기 위한 기준으로 사용한다.
- 이후 팀 논의를 통해 실제 정책 문서 또는 TC 분류 기준으로 확장할 수 있다.
